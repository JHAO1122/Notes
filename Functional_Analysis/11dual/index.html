    第十一章：对偶空间

    本章主要探讨赋范线性空间的对偶空间，并详细证明希尔伯特空间的 Riesz 表示定理以及 \(L^p\) 空间的对偶空间。随后将引入并证明泛函分析中极为重要的有界线性泛函延拓定理（Hahn-Banach 定理）与共鸣定理及其相关应用。

    1. 对偶空间与二次对偶空间

    1.1 对偶空间的定义

    定义 11.1 (对偶空间)

    赋范线性空间 \(E\) 上所有有界线性泛函构成了赋范线性空间，这个空间称为 \(E\) 的对偶空间（或共轭空间），记为 \(E^*\)。

    由于实（或复）数域 \(\mathbb{K}\) 是完备的，而 \(E^* = \mathbb{B}(E, \mathbb{K})\)。因为陪域 \(\mathbb{K}\) 完备，所以无论 \(E\) 自身是否完备，\(E^*\) 作为一个算子空间必定是完备的。也就是说，\(E^*\) 始终是一个 Banach 空间。

    \(E^*\) 中线性运算的定义：设 \(f_1, f_2 \in E^*\)，对任一 \(x \in E\)，有：

    \[ (f_1 + f_2)(x) = f_1(x) + f_2(x) \]
    \[ (\alpha f)(x) = \alpha f(x) \]

    范数的定义：

    \[ \|f\| = \sup_{x \in E, x \neq \theta} \frac{|f(x)|}{\|x\|} = \sup_{\|x\|=1} |f(x)| \]

    1.2 二次对偶空间与自反空间

    由于 \(E^*\) 自身是一个 Banach 空间，因此 \(E^*\) 也可以定义它自己的对偶空间，即 \((E^*)^*\)，称它为 \(E\) 的二次对偶空间，并简记为 \(E^{**}\)。以此类推，我们可以连续定义三次对偶空间 \(E^{***}\) 等等。

    设 \(x \in E\)，\(f \in E^*\)。在对偶空间的原始定义中，我们通常将泛函 \(f\) 视作给定的映射，而让自变量 \(x\) 跑遍整个空间 \(E\)。 反过来，如果我们固定线性空间中的元素 \(x\)，而让泛函 \(f\) 跑遍整个对偶空间 \(E^*\)，这时表达式 \(f(x)\) 就成了一个定义在 \(E^*\) 上的泛函，我们将其记为 \(x^{**}\)。即对任一 \(f \in E^*\)：

    \[ x^{**}(f) = f(x) \]

    定理 11.1 (典范映射的等距同构性)

    映射 \(E \rightarrow E^{**}: x \mapsto x^{**}\) 具有下列性质：

    (i) 映射是线性的，即若 \(x_1 \mapsto x_1^{**}\)，\(x_2 \mapsto x_2^{**}\)，则对任何实（或复）数 \(\alpha, \beta\)，有：

    \[ \alpha x_1 + \beta x_2 \mapsto \alpha x_1^{**} + \beta x_2^{**} \]

    (ii) 映射是等距的，因此它必然是一个单映射。

    定理 11.1 的证明（点击展开）

    Step 1: 证明 \(x^{**}\) 是一个有界线性泛函（即 \(x^{**} \in E^{**}\)）

    • 线性性：由对偶空间中泛函加法与数乘的定义 \((f_1 + f_2)(x) = f_1(x) + f_2(x)\) 及 \((\alpha f)(x) = \alpha f(x)\)，可知：
    \[ x^{**}(f_1 + f_2) = (f_1 + f_2)(x) = f_1(x) + f_2(x) = x^{**}(f_1) + x^{**}(f_2) \]
    \[ x^{**}(\alpha f) = (\alpha f)(x) = \alpha f(x) = \alpha x^{**}(f) \]
    • 有界性：根据有界线性泛函范数的定义，有：
    \[ |x^{**}(f)| = |f(x)| \le \|x\| \|f\| \]

    这说明当 \(x\) 固定时，该算子是有界的，并且其算子范数满足 \(\|x^{**}\| \le \|x\|\)。

    Step 2: 证明性质 (i) 映射是线性的

    • 对任一 \(f \in E^*\)，直接展开可得：
    \[ (\alpha x_1^{**} + \beta x_2^{**})(f) = \alpha x_1^{**}(f) + \beta x_2^{**}(f) = \alpha f(x_1) + \beta f(x_2) \]
    \[ = f(\alpha x_1) + f(\beta x_2) = f(\alpha x_1 + \beta x_2) = (\alpha x_1 + \beta x_2)^{**}(f) \]
    • 由于对所有 \(f \in E^*\) 上式均成立，由泛函相等性即得：
    \[ \alpha x_1^{**} + \beta x_2^{**} = (\alpha x_1 + \beta x_2)^{**} \]

    Step 3: 证明性质 (ii) 映射是等距的

    • 在 Step 1 中我们已经确立了方向的不等式：
    \[ \|x^{**}\| \le \|x\| \]
    • 另一方面，根据有界线性泛函延拓定理（Hahn-Banach 定理）的重要推论，对于给定的非零元素 \(x \in E\)，必定存在一个有界线性泛函 \(f_0 \in E^*\) 使得：
    \[ \|f_0\| = 1 \quad \text{且} \quad f_0(x) = \|x\| \]
    • 此时，将该特殊的泛函 \(f_0\) 代入 \(x^{**}\) 的定义式中，有：
    \[ \|x^{**}\| = \sup_{\|f\|=1} |x^{**}(f)| \ge |x^{**}(f_0)| = |f_0(x)| = \|x\| \]
    • 综合上述两个方向的不等式，可以得出：
    \[ \|x^{**}\| = \|x\| \]

    由于该映射完美保持了空间元素的范数，所以它必然是一个单映射。 \(\square\)

    定义 11.2 (自反空间)

    映射 \(x \mapsto x^{**}\) 是 \(E\) 到 \(E^{**}\) 中的一个等距映射，在泛函分析中通常称它为 \(E\) 到 \(E^{**}\) 的典范映射。

    • 典范映射始终是等距同构的，但它不一定是满映射。当它是满映射时（即典范映射的值域填满了整个二次对偶空间 \(E^{**}\)），我们称空间 \(E\) 是自反空间。

    • 我们可以将 \(E\) 与它在典范映射下的像空间视作完全一致。因此，在不计等距同构的意义下，\(E\) 可以被看成是 \(E^{**}\) 的一个子空间。在这样的观点下，若 \(E = E^{**}\)，则空间被称为自反空间。

    2. 希尔伯特空间上的有界线性泛函

    在 Hilbert 空间 \(H\) 中，由于内质结构（内积）的存在，有界线性泛函具有非常形象且优美具体的代数表达形式，这由 Riesz 表示定理给出。

    定理 11.2 (Riesz 表示定理)

    设 \(f\) 是 Hilbert 空间 \(H\) 上的有界线性泛函。必存在唯一的 \(u \in H\) 使得：

    \[ f(x) = (x, u) \]

    并且满足范数等距关系 \(\|f\| = \|u\|\)。

    反之，对任意给定的元素 \(u \in H\)，由等式 \(f(x) = (x, u)\) 唯一确定了 \(H\) 上的一个有界线性泛函，且其算子范数正好等于 \(\|u\|\)。

    Riesz 表示定理的证明（点击展开）

    1. 存在性的证明：

    • 设 \(f = 0\) 是零泛函，此时显然只需取 \(u = \theta\)，等式与范数关系自然成立。下面我们不妨设 \(f \neq 0\)。

    • 令泛函的零空间为：

    \[ L := \{x \in H \mid f(x) = 0\} \]
    • 由于泛函 \(f\) 是线性且连续的，其原像零空间 \(L\) 是 \(H\) 的一个真闭子空间。根据希尔伯特空间的正交分解定理，存在非零元素属于其正交补空间，即存在非零的 \(x_0 \in L^\perp\)。为了计算方便，我们不妨进行单位化，设 \(\|x_0\| = 1\)。此时整个空间可以作如下分解：
    \[ H = L \oplus \mathbb{K}\{x_0\} \]
    • 令常数 \(\alpha = f(x_0)\)。对于任意一个元素 \(x \in H\)，我们构造如下元素：
    \[ x - \frac{f(x)}{\alpha} x_0 \]
    • 利用泛函 \(f\) 的线性性质，对其求取泛函值：
    \[ f\left(x - \frac{f(x)}{\alpha} x_0\right) = f(x) - \frac{f(x)}{\alpha} f(x_0) = f(x) - \frac{f(x)}{\alpha} \cdot \alpha = 0 \]
    • 这说明元素 \(x - \frac{f(x)}{\alpha} x_0\) 属于零空间 \(L\)。由此，任何 \(x\) 都可以被唯一分解为两部分的和：
    \[ x = \left(x - \frac{f(x)}{\alpha} x_0\right) + \frac{f(x)}{\alpha} x_0 \]
    • 考虑将上式两边同时与之前选取的特殊元素 \(x_0\) 做内积。由于第一部分属于 \(L\)，而 \(x_0 \in L^\perp\)，两者的内积为零：
    \[ (x, x_0) = \left(x - \frac{f(x)}{\alpha} x_0, x_0\right) + \left(\frac{f(x)}{\alpha} x_0, x_0\right) = 0 + \frac{f(x)}{\alpha} \|x_0\|^2 = \frac{f(x)}{\alpha} \]
    • 由此我们解出泛函值的表达式为：
    \[ f(x) = \alpha (x, x_0) \]
    • 根据内积关于第二变元的共轭线性性质，我们可以把常数项移入内积内部：
    \[ f(x) = (x, \overline{\alpha} x_0) \]
    • 此时，只需令 \(u = \overline{\alpha} x_0 = \overline{f(x_0)} x_0\)，我们就找到了能够表示泛函 \(f\) 的元素 \(u \in H\)，存在性得证。

    2. 唯一性的证明：

    • 假设在空间中还存在另一个元素 \(u' \in H\)，使得对于一切的 \(x \in H\) 均满足表示式 \(f(x) = (x, u')\)。

    • 那么我们有：

    \[ (x, u) = (x, u') \implies (x, u - u') = 0 \]

    • 上式对整个空间 \(H\) 中的所有 \(x\) 都要成立。这意味着向量 \(u - u'\) 与整个空间 \(H\) 相互正交。

    • 我们取特殊的 \(x = u - u'\) 代入其中，可得 \(\|u - u'\|^2 = 0\)。根据内积的正定性，必有 \(u - u' = \theta\)，即 \(u = u'\)。唯一性得证统一。

    3. 范数等距关系 \(\|f\| = \|u\|\) 的证明：

    • 一方面，根据 Cauchy-Schwarz 不等式，对于任意的 \(x \in H\)，有：
    \[ |f(x)| = |(x, u)| \le \|x\| \|u\| \]

    根据有界线性泛函范数的上确界定义，直接推导出 \(\|f\| \le \|u\|\)。

    • 另一方面，我们在空间中取特殊的自变量 \(x = u\) 代入，有：
    \[ |f(u)| = |(u, u)| = \|u\|^2 \]

    若 \(u \neq \theta\)，根据范数的定义式可得：

    \[ \|f\| = \sup_{x \neq \theta} \frac{|f(x)|}{\|x\|} \ge \frac{|f(u)|}{\|u\|} = \frac{\|u\|^2}{\|u\|} = \|u\| \]
    • 联合两边的不等式，我们确立了算子范数与向量范数的严格等距关系：
    \[ \|f\| = \|u\| \]
    • 反之，若已知元素 \(u \in H\)，利用内积的性质以及 Cauchy-Schwarz 不等式，可以非常容易地验证 \(f(x) = (x, u)\) 确实满足有界线性的要求。其范数相等的证明过程与上面完全一致。 \(\square\)

    2.1 Hilbert 空间的自对偶性

    根据 Riesz 表示定理，我们可以建立起一个从 Hilbert 空间 \(H\) 到其对偶空间 \(H^*\) 的映射：\(u \mapsto f = (\cdot, u)\)。 假设还有另一个元素 \(v \mapsto g = (\cdot, v)\)，那么根据内积的代数运算性质，显然有：

    \[ u + v \mapsto f + g = (\cdot, u) + (\cdot, v) = (\cdot, u + v) \]

    对于任意给定的实数或复数标量 \(\alpha\)，由于内积对第二变元具有共轭性，我们有：

    \[ \alpha u \mapsto \overline{\alpha} f \]

    这是因为如果我们将元素 \(\alpha u\) 映射为泛函 \(h\)，那么对任意 \(x \in H\)，其泛函值展开为：

    \[ h(x) = (x, \alpha u) = \overline{\alpha}(x, u) = \overline{\alpha}f(x) \]

    与内积空间的基本定义类似： * 当 \(H\) 为实空间时，映射 \(u \mapsto f\) 是完全线性的； * 当 \(H\) 为复空间时，映射 \(u \mapsto f\) 满足复共轭规律，我们称其为共轭线性的（或反线性的）。

    根据 Riesz 表示定理中确立的范数等距关系 \(\|f\| = \|u\|\) 可知，该映射构成了空间到对偶空间上的等距同构（或等距共轭同构）映射。

    我们可以在对偶空间 \(H^*\) 中极其自然地诱导一个内积结构：对于任意通过映射得到的泛函 \(f\)（源自 \(u\)）与 \(g\)（源自 \(v\)），定义它们之间的内积为：

    \[ (f, g)_{H^*} := \overline{(u, v)}_H = (v, u)_H \]

    在这种内积定义下，\(H^*\) 本身完美地构成了一个 Hilbert 空间。于是，两个希尔伯特空间 \(H\) 与 \(H^*\) 之间可以通过该等距同构实现结构上的完全对等。我们将它们视作同一个空间，即 \(\mathcal{H} = \mathcal{H}^*\)。这一极其核心的性质被称为 Hilbert 空间的自对偶性或自共轭性。

    3. \(L^p[a,b]\) 空间的对偶空间

    除了完备的内积空间 \(L^2[a,b]\) 之外，泛函分析中对于一般的 Lebesgue 可积函数空间 \(L^p[a,b]\) 的对偶空间也能够给出非常确定且具体的代数表示定理。

    定理 11.3

    设 \(1 < p < \infty\)。则空间 \(L^p[a,b]\) 的对偶空间可以与其共轭指数空间实现等距同构：

    \[ (L^p[a,b])^* = L^q[a,b] \]

    这里 \(p\) 和 \(q\) 满足经典的共轭指数关系：\(\frac{1}{p} + \frac{1}{q} = 1\)。

    定理 11.3 的证明（点击展开）

    Step 1: 构造从 \(L^q[a,b]\) 到 \((L^p[a,b])^*\) 的算子映射 \(T\)

    • 任取函数 \(y \in L^q[a,b]\)。对于任何给定的函数 \(x \in L^p[a,b]\)，我们通过积分表达式定义一个泛函：
    \[ f(x) = \int_a^b x(t)y(t) dt \]
    • 根据测度论中的 Hölder 不等式，积分的绝对值满足：
    \[ \int_a^b |x(t)y(t)| dt \le \left(\int_a^b |x(t)|^p dt\right)^{\frac{1}{p}} \left(\int_a^b |y(t)|^q dt\right)^{\frac{1}{q}} = \|x\|_p \|y\|_q \]

    这说明对于一切 \(x \in L^p[a,b]\)，该积分都是有界且确定存在的。

    • 由积分的基本性质可知，泛函 \(f\) 在 \(L^p\) 空间上满足线性要求。同时，上述不等式表明 \(|f(x)| \le \|y\|_q \|x\|_p\)，从而进一步说明该泛函是有界的，且其算子范数满足方向的不等式：
    \[ \|f\| \le \|y\|_q \]
    • 我们构造映射 \(T: L^q[a,b] \longrightarrow (L^p[a,b])^*\)，其对应法则为 \(y \mapsto f\)。显然算子 \(T\) 满足线性性质，且由上式知其有界。因此 \(T\) 是由 \(L^q\) 空间映射到 \(L^p\) 对偶空间中的一个有界线性算子。

    Step 2: 利用反证法证明映射 \(T\) 是单映射

    • 假设该映射不是单射。那么必然存在一个非零的元 \(y \neq \theta\)，使得其映射后的泛函为零泛函，即 \(f = Ty = \theta\)。

    • 由于 \(y\) 在空间中非零，必定存在某个足够小的正数 \(N > 0\)，使得集合 \(e_N = \{t \in [a,b] \mid |y(t)| \ge N\}\) 的 Lebesgue 测度严格大于零，即 \(m(e_N) > 0\)。

    • 针对此集合，我们专门构造如下的一个测试函数：

    \[ \chi_N(t) = \begin{cases} \text{sgn } y(t), & t \in e_N \\ 0, & t \notin e_N \end{cases} \]

    显然，\(\chi_N(t)\) 作为一个有界且支集测度有限的函数，必然属于空间 \(L^p[a,b]\)。

    • 我们将该测试函数代入泛函 \(f\) 的积分式中进行计算：
    \[ f(\chi_N) = \int_a^b \chi_N(t)y(t) dt = \int_{e_N} \text{sgn}(y(t)) \cdot y(t) dt = \int_{e_N} |y(t)| dt \ge N \cdot m(e_N) > 0 \]

    这说明泛函 \(f\) 并不是零泛函（\(f \neq \theta\)），这与最初的假设产生了无法调和的矛盾。因此，映射 \(T\) 必须是单映射。

    Step 3: 证明映射 \(T\) 是满映射（泛函的绝对连续性表示）

    • 设 \(f\) 是 \(L^p[a,b]\) 空间上任意给定的一个有界线性泛函。对于区间上的任意点 \(s \in [a,b]\)，我们记 \(\chi_s\) 为子区间 \([a,s]\) 的特征函数。我们定义辅助函数：
    \[ g(s) = f(\chi_s) \]

    接下来我们将严密证明 \(g\) 是 \([a,b]\) 上的一个绝对连续函数。

    • 设 \(\delta_j = [s_j, t_j]\) (\(j=1,2,\dots,n\)) 是一组包含在 \([a,b]\) 内部且彼此之间没有公共内点的闭区间。我们记常数项符号为 \(\epsilon_j = \text{sgn}[g(t_j) - g(s_j)]\)。

    • 利用泛函 \(f\) 的线性与有界性，进行如下推导：

    \[ \sum_{j=1}^n |g(t_j) - g(s_j)| = \sum_{j=1}^n \epsilon_j [g(t_j) - g(s_j)] = \sum_{j=1}^n \epsilon_j [f(\chi_{t_j}) - f(\chi_{s_j})] \]
    \[ = f\left( \sum_{j=1}^n \epsilon_j [\chi_{t_j} - \chi_{s_j}] \right) \le \|f\| \cdot \left\| \sum_{j=1}^n \epsilon_j [\chi_{t_j} - \chi_{s_j}] \right\|_p \]
    \[ = \|f\| \cdot \left( \int_a^b \left| \sum_{j=1}^n \epsilon_j [\chi_{t_j} - \chi_{s_j}] \right|^p dt \right)^{\frac{1}{p}} \]
    • 注意到这些区间 \(\delta_j\) 互不相交，因此上述积分可以完全拆分为各个区间上的独立积分之和：
    \[ = \|f\| \cdot \left( \sum_{j=1}^n \int_{\delta_j} |\epsilon_j|^p dt \right)^{\frac{1}{p}} = \|f\| \cdot \left( \sum_{j=1}^n m(\delta_j) \right)^{\frac{1}{p}} \]
    • 依据上述最终放缩形式，任给给定正数 \(\epsilon > 0\)，我们只需挑选相应的控制变量 \(\delta = \left( \frac{\epsilon}{\|f\|} \right)^p\)。那么只要区间的总长度满足 \(\sum_{j=1}^n m(\delta_j) < \delta\)，就会严格导致：
    \[ \sum_{j=1}^n |g(t_j) - g(s_j)| < \epsilon \]

    这完全符合绝对连续函数的定义。因此 \(g\) 必定是绝对连续函数。

    • 依据绝对连续函数的经典微积分定理，函数 \(g\) 几乎处处可导，且其导函数可积。我们令 \(y(s) = g'(s)\)，则 \(y \in L[a,b]\)。再结合边界条件 \(g(a) = f(\chi_a) = f(\theta) = 0\)，通过微积分基本定理可以写出：
    \[ f(\chi_s) = g(s) = \int_a^s y(t) dt = \int_a^b \chi_s(t)y(t) dt \]

    • 上式证明了积分表达式对于任意基本特征函数均成立。由于任何阶梯函数都可以写成这种特征函数的有限线性组合，基于泛函 \(f\) 的线性，该积分表达式对于所有阶梯函数同样严格成立。

    • 进一步，设 \(x\) 是定义在 \([a,b]\) 上的任意有界可测函数。根据实变函数稠密性，我们可以选取一个一致有界的阶梯函数列 \(\{x_n\}\)，使其在区间上几乎处处收敛于 \(x\)。

    • 根据测度论中的有界收敛定理，我们有：

    \[ \lim_{n \to \infty} \int_a^b x_n(t)y(t) dt = \int_a^b x(t)y(t) dt \]

    同时，这列函数在 \(L^p\) 范数下也强烈收敛：

    \[ \|x_n - x\|_p = \left( \int_a^b |x_n(t) - x(t)|^p dt \right)^{\frac{1}{p}} \longrightarrow 0 \]
    • 在关系式 \(f(x_n) = \int_a^b x_n(t)y(t) dt\) 两边同时令 \(n \rightarrow \infty\)。由泛函 \(f\) 的有界连续性，我们把结论成功推广到了所有的有界可测函数：
    \[ f(x) = \int_a^b x(t)y(t) dt \]

    Step 4: 证明生成的核函数 \(y\) 属于空间 \(L^q[a,b]\) 且满足范数控制

    • 为了消除有界可测的局限性，我们需要定量估计 \(y\) 的范数。我们在区间 \([a,b]\) 上专门引入如下带有截断性质的有界可测函数列：
    \[ y_N(t) = \begin{cases} |y(t)|^{q-1} \text{sgn } y(t), & |y(t)| \le N \\ 0, & |y(t)| > N \end{cases} \]

    这里 \(N\) 为任意给定的正数。记对应的有限约束集合为 \(E_N = \{t \in [a,b] \mid |y(t)| \le N\}\)。

    • 将此有界可测函数 \(y_N\) 作为自变量直接代入 Step 3 中确立的泛函表达式中：
    \[ f(y_N) = \int_a^b y_N(t)y(t) dt = \int_{E_N} |y(t)|^{q-1} \text{sgn}(y(t)) \cdot y(t) dt = \int_{E_N} |y(t)|^q dt \]
    • 另一方面，我们利用泛函 \(f\) 原本的有界性控制关系式 \(f(y_N) \le \|f\| \|y_N\|_p\) 进行估计：
    \[ f(y_N) \le \|f\| \cdot \left( \int_a^b |y_N(t)|^p dt \right)^{\frac{1}{p}} = \|f\| \cdot \left( \int_{E_N} \left( |y(t)|^{q-1} \right)^p dt \right)^{\frac{1}{p}} \]
    • 注意到共轭指数关系满足 \((q-1)p = q\)，将此代入上式的积分幂次项中，可得：
    \[ f(y_N) \le \|f\| \cdot \left( \int_{E_N} |y(t)|^q dt \right)^{\frac{1}{p}} \]
    • 联合上述关于 \(f(y_N)\) 的上下界两个不等式，我们得到：
    \[ \int_{E_N} |y(t)|^q dt \le \|f\| \cdot \left( \int_{E_N} |y(t)|^q dt \right)^{\frac{1}{p}} \]
    • 将右侧的项移项至左侧（等价于两边同时除以该积分的 \(1/p\) 次幂），由于 \(1 - \frac{1}{p} = \frac{1}{q}\)，我们成功导出了关键的有界控制关系：
    \[ \left( \int_{E_N} |y(t)|^q dt \right)^{\frac{1}{q}} \le \|f\| \]
    • 现在让截断参数趋于无穷大（\(N \rightarrow \infty\)）。根据单调收敛定理，左侧的局部积分项完美过渡到整个空间上的积分，从而确立了：
    \[ \|y\|_q = \left( \int_a^b |y(t)|^q dt \right)^{\frac{1}{q}} \le \|f\| \]

    这不仅严格证明了核函数 \(y \in L^q[a,b]\)，还给出了算子范数的下界估计。

    Step 5: 最终推广至整个空间 \(L^p[a,b]\)

    • 对于任意一个一般的函数 \(x \in L^p[a,b]\)，由于有界可测函数集在 \(L^p\) 空间中稠密，我们一定可以找到一列有界可测函数 \(\{x_n\}\)，使得在 \(L^p\) 范数意义下有：
    \[ \int_a^b |x_n(t) - x(t)|^p dt \longrightarrow 0 \]

    • 由于对每一项有界可测函数 \(x_n\)，关系式 \(f(x_n) = \int_a^b x_n(t)y(t) dt\) 都已经严格成立。此时我们在等式两边同时令 \(n \rightarrow \infty\)。

    • 左侧由泛函的连续性收敛于 \(f(x)\)；右侧由已证的 \(y \in L^q\) 结合 Hölder 不等式同样收敛于 \(\int_a^b x(t)y(t) dt\)。

    • 于是，我们证明了对于整个 \(L^p[a,b]\) 空间中的一切元素，都有如下积分表示式成立：

    \[ f(x) = \int_a^b x(t)y(t) dt \]

    且结合 Step 1 的上界与 Step 4 的下界可知 \(\|f\| = \|y\|_q\)。这说明映射 \(T\) 确实是一个满的等距同构。 \(\square\)
