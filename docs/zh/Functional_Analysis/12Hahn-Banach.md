# 第十二章：有界线性泛函的延拓与共鸣定理

本章重点讨论有界线性泛函的延拓理论，详细证明泛函分析中最为核心的基石定理之一——**Hahn-Banach 延拓定理**（包括实线性空间与复线性空间版本），并深入探讨其在赋范线性空间中的一系列极其重要的推论。

---

## 1. 线性泛函的延拓概念

在探讨有界线性泛函的延拓之前，一个根本性的问题摆在我们面前：在一个一般的、只含有非零元素的赋范线性空间上，是否一定存在非零的有界线性泛函？

为了回答这个关于非零有界线性泛函“存在性”的根本问题，我们必须深入研究有界线性泛函的延拓理论。

!!! info "定义 12.1 (延拓)"

    设 $E$ 是一个线性空间，$f_1$ 和 $f_2$ 分别是定义在 $E$ 的子空间 $G_1$ 和 $G_2$ 上的线性泛函。如果它们满足以下两个条件：
  
    (i) $G_1 \subset G_2$；
  
    (ii) 对任一 $x \in G_1$，都有 $f_1(x) = f_2(x)$；
  
    则称 $f_2$ 是 $f_1$ 在 $G_2$ 上的一个**延拓**。

---

## 2. 次可加与正齐次泛函

为了给 Hahn-Banach 定理的控制边界建立数学工具，我们首先引入两类特殊的泛函结构。

!!! info "定义 12.2 (次可加与正齐次)"

    设 $E$ 为线性空间，$p$ 为定义在 $E$ 上的实值泛函。
  
    * 如果对任意的 $x, y \in E$，恒有：

        \[
        p(x + y) \le p(x) + p(y)
        \]

        则称 $p$ 为**次可加的**。
  
    * 如果对任意的实数 $a \ge 0$ 以及任意的 $x \in E$，恒有：

        \[
        p(ax) = a p(x)
        \]

        则称 $p$ 为**正齐次的**。

---

## 3. Hahn-Banach 延拓定理（实空间版本）

这是 Hahn-Banach 定理最经典的核心代数版本，它表明在次可加正齐次泛函的控制下，实线性子空间上的线性泛函总可以被延拓到全空间。

!!! success "定理 12.1 (Hahn-Banach 延拓定理 - 实空间版)"

    设 $G$ 为**实线性空间** $E$ 的子空间，$f$ 是定义在 $G$ 上的实线性泛函，$p$ 是定义在 $E$ 上的次可加正齐次泛函。
  
    若 $f$ 满足控制条件：对一切 $x \in G$，恒有 $f(x) \le p(x)$。
  
    则必存在定义在整个空间 $E$ 上的实线性泛函 $F$，满足：
  
    (i) 当 $x \in G$ 时，$F(x) = f(x)$，即 $F$ 是 $f$ 在 $E$ 上的一个延拓；
  
    (ii) 当 $x \in E$ 时，恒有 $F(x) \le p(x)$。

??? proof "定理 12.1 的证明（点击展开）"

    本定理的证明采用逐步一维延拓法，再结合超限归纳法（Zorn 引理）。

    **第一步：证明单维延拓的可能性**

    * 如果 $G = E$，则直接取 $F = f$ 即可，定理显然成立。
  
    * 不妨设 $G \neq E$，此时必定可以任意选取一个元素 $x_0 \in E \backslash G$。
  
    * 我们令 $G_1$ 是由子空间 $G$ 与元素 $x_0$ 共同张成的扩大子空间：

        \[
        G_1 := \{ \alpha x_0 + x \mid \alpha \in \mathbb{R}, x \in G \}
        \]

    * 对于任何 $x', x'' \in G$，利用 $f$ 的线性和 $p$ 的次可加性，有：

        \[
        f(x'') - f(x') = f(x'' - x') \le p(x'' - x') = p((x'' + x_0) + (-x' - x_0)) \le p(x'' + x_0) + p(-x' - x_0)
        \]

    * 将项移项移位，可以得到：

        \[
        -p(-x' - x_0) - f(x') \le p(x'' + x_0) - f(x'')
        \]

    * 上式左端仅与 $x'$ 有关，右端仅与 $x''$ 有关，且对所有 $x', x'' \in G$ 均成立。因此，左端的上确界必然不超过右端的下确界：

        \[
        c' = \sup_{x' \in G} \{ -p(-x' - x_0) - f(x') \} \le c'' = \inf_{x'' \in G} \{ p(x'' + x_0) - f(x'') \}
        \]

    * 我们在闭区间 $[c', c'']$ 中任取一个实数 $c$，满足 $c' \le c \le c''$。现在我们在扩大空间 $G_1$ 上定义一个新的泛函 $\tilde{f}$：

        \[
        \tilde{f}(\alpha x_0 + x) := \alpha c + f(x)
        \]

    * 由于 $G_1$ 中的每个元素均可唯一地表示成 $\alpha x_0 + x$ 的形式，因此上述表达式唯一地定义了一个线性泛函 $\tilde{f}$。

    **第二步：验证 $\tilde{f}$ 满足控制条件 $\tilde{f}(\alpha x_0 + x) \le p(\alpha x_0 + x)$**

    * 1. 若 $\alpha = 0$，则 $\tilde{f}(x) = f(x) \le p(x)$，控制条件显然成立。
  
    * 2. 若 $\alpha > 0$，由 $c \le c''$ 的取法，有：

        \[
        c \le \inf_{x'' \in G} \{ p(x'' + x_0) - f(x'') \} \le p\left( \frac{x}{\alpha} + x_0 \right) - f\left( \frac{x}{\alpha} \right)
        \]

        故有：

        \[
        c + f\left( \frac{x}{\alpha} \right) \le p\left( \frac{x}{\alpha} + x_0 \right)
        \]

        两边同时乘以正数 $\alpha$，利用 $f$ 的线性和 $p$ 的正齐次性，得到：

        \[
        \alpha c + f(x) \le p(x + \alpha x_0)
        \]

    * 3. 若 $\alpha < 0$，由 $c' \le c$ 的取法，有：

        \[
        -p\left( -\frac{x}{\alpha} - x_0 \right) - f\left( -\frac{x}{\alpha} \right) \le c
        \]

        通过变号与整理，得到：

        \[
        -c - f\left( \frac{x}{\alpha} \right) \le p\left( -\frac{x}{\alpha} - x_0 \right)
        \]

        两边同时乘以正数 $-\alpha$，同样利用正齐次性，得到：

        \[
        \alpha c + f(x) \le p(x + \alpha x_0)
        \]

    * 综上所述，我们严格证明了线性泛函可以成功向外延拓一个维度，并且在新空间 $G_1$ 上控制条件依然保持。

    **第三步：利用 Zorn 引理完成全空间延拓**

    * 我们用 $\mathscr{F}$ 表示 $f$ 的一切满足控制条件 $F(x) \le p(x)$ 的代数延拓 $F$ 构成的集合，这里 $x$ 属于 $F$ 的定义域 $D_F$。由于第二步已经证明可以合法延拓到 $G_1$ 上，故集合 $\mathscr{F}$ 是**非空集合**。
  
    * 在 $\mathscr{F}$ 中规定一个偏序关系：对任意的 $F_1, F_2 \in \mathscr{F}$，若 $F_2$ 是 $F_1$ 的一个延拓（即 $D_{F_1} \subset D_{F_2}$ 且在其上相等），则称 $F_2$ 在 $F_1$ 之后，记为 $F_1 \prec F_2$。在此偏序下，$\mathscr{F}$ 成为一个半序集。
  
    * 设 $\mathscr{M}$ 是 $\mathscr{F}$ 中的任意一个全序子集。我们定义一个整体定义域：

        \[
        D = \bigcup_{F \in \mathscr{M}} D_F
        \]

    * 在 $D$ 上我们以如下方式定义一个整体泛函 $\varphi$：任取 $x \in D$，则其必属于某个 $D_F$（其中 $F \in \mathscr{M}$），令：

        \[
        \varphi(x) = F(x)
        \]

    * 由于 $\mathscr{M}$ 是全序集，此定义是良好确定的（well-defined），且易证 $\varphi$ 是以 $D$ 为定义域的线性泛函，同时对一切 $x \in D$ 均满足 $\varphi(x) \le p(x)$。
  
    * 显然 $\varphi$ 是 $\mathscr{M}$ 中所有元素的一个上界，故 $\varphi \in \mathscr{F}$。半序集 $\mathscr{F}$ 满足 Zorn 引理的条件，因此 $\mathscr{F}$ 必定存在一个极大元，我们用 $F_0$ 表示。
  
    * 此时，极大元 $F_0$ 的定义域 $D_{F_0}$ 必须等于全空间 $E$。
  
    * 如果不等于 $E$（即 $D_{F_0} \neq E$），那么我们完全可以根据第一步和第二步的方法，将 $F_0$ 再向外延拓一个维度到某个 $E_1$ 上，记为 $F_1$，且其依然满足控制条件。这说明 $F_1 \in \mathscr{F}$ 且 $F_0 \prec F_1$ ($F_0 \neq F_1$)，这与 $F_0$ 的极大性产生根本矛盾。
  
    * 从而必有 $D_{F_0} = E$。取 $F = F_0$，即完成了全空间实线性延拓的证明。 $\square$

## 4. Hahn-Banach 延拓定理（复空间版本）

利用复泛函可以完全由其实部唯一确定的性质，我们可以将定理完美推广到复线性空间（亦称 Bohnenblust-Sobczyk 定理）。

!!! success "定理 12.2 (Hahn-Banach 延拓定理 - 复空间版/泛 Norm 版)"

    设 $G$ 是复（或实）线性空间 $E$ 的子空间，$p$ 是定义在 $E$ 上的半范数（满足次可加性与绝对齐次性：$p(\alpha x) = |\alpha|p(x)$）。$f$ 是定义在 $G$ 上的有界线性泛函，且满足控制条件：

    \[
    |f(x)| \le p(x) \quad (\forall x \in G)
    \]

    则必存在定义在整个空间 $E$ 上的线性泛函 $F$，满足：
  
    (i) $F$ 是 $f$ 在 $E$ 上的延拓，即当 $x \in G$ 时，$F(x) = f(x)$；
  
    (ii) 对一切 $x \in E$，控制条件依然保持： $|F(x)| \le p(x)$

??? proof "定理 12.2 的复空间版本证明（点击展开）"

    我们重点给出复线性空间下的证明思路与细节。

    **第一步：拆分实部**

    * 设 $f$ 是复线性泛函，我们将其拆分为实部与虚部：$f(x) = \varphi_0(x) + i \psi_0(x)$，其中 $\varphi_0, \psi_0$ 是实值泛函。
  
    * 利用复线性性质 $f(ix) = i f(x)$，展开可得：

        \[
        \varphi_0(ix) + i \psi_0(ix) = i (\varphi_0(x) + i \psi_0(x)) = -\psi_0(x) + i \varphi_0(x)
        \]

    * 对比实部与虚部，可得 $\psi_0(x) = -\varphi_0(ix)$。因此，复线性泛函可以完全由其实部表示：

        \[
        f(x) = \varphi_0(x) - i \varphi_0(ix)
        \]

    **第二步：延拓实部**

    * 易知 $\varphi_0$ 是实线性空间 $G$ 上的实线性泛函，且满足 $\varphi_0(x) = \text{Re } f(x) \le |f(x)| \le p(x)$。
  
    * 依据已经证明的实空间版本 Hahn-Banach 定理（定理 12.1），我们可以将 $\varphi_0$ 延拓到整个空间 $E$ 上的实线性泛函 $\varphi$，并且在整个 $E$ 上满足：

        \[
        \varphi(x) \le p(x)
        \]

    **第三步：重构复泛函并验证线性结构**

    * 仿照第一步的形式，我们在整个全空间 $E$ 上重构复泛函 $F$：

        \[
        F(x) = \varphi(x) - i \varphi(ix)
        \]

    * 我们验证 $F$ 满足复线性算子的性质。对于任意的 $x \in E$，有：

        \[
        F(ix) = \varphi(ix) - i \varphi(-x) = \varphi(ix) + i \varphi(x) = i [ \varphi(x) - i \varphi(ix) ] = i F(x)
        \]

    * 结合 $\varphi$ 的实线性，容易验证 $F$ 为复线性泛函。当 $x \in G$ 时，由于 $\varphi$ 是 $\varphi_0$ 的延拓，显然有 $F(x) = f(x)$。

    **第四步：验证绝对值控制条件**

    * 任取 $x \in E$。我们将其复数值 $F(x)$ 写成极坐标形式（辐角为 $\alpha$）：$F(x) = |F(x)|e^{i\alpha}$。
  
    * 那么，显然 $e^{-i\alpha}F(x) = |F(x)|$ 是一个非负的实数。利用 $F$ 的复线性和定义式，有：

        \[
        |F(x)| = e^{-i\alpha}F(x) = F(e^{-i\alpha}x) = \text{Re } F(e^{-i\alpha}x) = \varphi(e^{-i\alpha}x)
        \]

    * 此时，代入 $\varphi$ 在实版定理中受到的 $p$ 的控制关系，并结合半范数 $p$ 的绝对齐次性，得到：

        \[
        |F(x)| \le p(e^{-i\alpha}x) = |e^{-i\alpha}| p(x) = p(x)
        \]

    * 绝对值控制条件在全空间上得以保持，复空间版本证毕。 $\square$

## 5. 赋范线性空间中的重要推论

在赋范线性空间中，若取 $p(x) = \|f\|_G \cdot \|x\|$，Hahn-Banach 定理直接演变为有界线性泛函的**保范延拓定理**。由此可以导出一系列极为关键的几何与拓扑性质。

### 推论 12.3 (保范延拓)

设 $G$ 是赋范线性空间 $E$ 的子空间，$f$ 是定义在 $G$ 上的有界线性泛函。则必存在定义在整个空间 $E$ 上的有界线性泛函 $F$，使得 $F$ 是 $f$ 的延拓，且它们的算子范数严格相等：

\[
\|F\|_E = \|f\|_G
\]

---

### 推论 12.4 (非零泛函的存在性)

设 $E$ 是赋范线性空间，$x_0 \in E$ 是空间中的一个任意非零元素（$x_0 \neq \theta$）。则在对偶空间 $E^*$ 中必定存在一个有界线性泛函 $f_0$，满足以下性质：

(i) $\|f_0\| = 1$；

(ii) $f_0(x_0) = \|x_0\|$。

这完美回答了本章开头提出的非零有界线性泛函的存在性问题。

---

### 推论 12.5 (元素的范数的对偶表示)

对于赋范线性空间 $E$ 中的任意元素 $x$，其范数可以通过跑遍对偶空间单位球的泛函的上确界来等价表示：

\[
\|x\| = \sup_{f \in E^*, \|f\|=1} |f(x)|
\]

---

### 推论 12.6 (点与子空间的分离定理)

设 $G$ 是赋范线性空间 $E$ 的一个子空间，且点 $x_0 \in E$ 到子空间 $G$ 的有截距离满足：

\[
d = \inf_{x \in G} \|x_0 - x\| > 0
\]

则在对偶空间 $E^*$ 中必定存在一个有界线性泛函 $f$，满足以下分离性质：

(i) $\|f\| = 1$；

(ii) 对一切 $x \in G$，恒有 $f(x) = 0$（即 $f \in G^\perp$）；

(iii) $f(x_0) = d$。

## 6. 共鸣定理及其应用

在泛函分析中，除了开映射定理和闭图像定理外，还有一个极为核心的基本定理，它深刻揭示了算子族的点态有界性与一致有界性之间的内在联系。这个定理通常被称为**一致有界性原理 (Uniform Boundedness Principle)**，在经典文献中也常被称为**共鸣定理 (Resonance Theorem)**。

### 6.1 共鸣定理 (一致有界性原理)

!!! info "定理 12.3 (共鸣定理 / 一致有界性原理)"

    设 $X$ 是一个 Banach 空间，$Y$ 是一个赋范线性空间。
    
    设 $\{T_\alpha\}_{\alpha \in I}$ 是从 $X$ 到 $Y$ 的一族有界线性算子（其中 $I$ 为任意指标集）。
    
    如果对于每一个固定的 $x \in X$，该算子族在 $x$ 处的像集在 $Y$ 中是有界的，即存在常数 $C_x > 0$ 使得：

    \[
    \sup_{\alpha \in I} \|T_\alpha x\| \le C_x < \infty
    \]

    那么，该算子族在算子范数意义下必定是一致有界的。即存在一个统一的常数 $M > 0$，使得对于所有的 $\alpha \in I$，恒有：

    \[
    \sup_{\alpha \in I} \|T_\alpha\| \le M < \infty
    \]

??? proof "共鸣定理的证明（点击展开）"

    本定理的证明深刻依赖于完备度量空间中的 **Baire 纲定理**。

    对于每一个正整数 $n$，我们定义集合：

    \[
    X_n = \left\{ x \in X \;\middle|\; \|T_\alpha x\| \le n, \quad \forall \alpha \in I \right\}
    \]

    首先，我们证明 $X_n$ 是闭集。由于每一个算子 $T_\alpha$ 都是连续的（有界线性算子），函数 $x \mapsto \|T_\alpha x\|$ 也是连续的。因此，集合 $\{x \in X \mid \|T_\alpha x\| \le n\}$ 是一个闭集。
    
    而 $X_n$ 正是这些闭集对所有 $\alpha \in I$ 的交集：

    \[
    X_n = \bigcap_{\alpha \in I} \left\{ x \in X \;\middle|\; \|T_\alpha x\| \le n \right\}
    \]

    任意多个闭集的交集依然是闭集，因此 $X_n$ 必定是 $X$ 中的闭集。

    根据定理的假设，对于空间 $X$ 中的任意一个元素 $x$，集合 $\{ \|T_\alpha x\| \}_{\alpha \in I}$ 是有界的。这意味着一定存在某个足够大的整数 $n$，使得对所有的 $\alpha \in I$，都有 $\|T_\alpha x\| \le n$。
    
    这就说明，空间 $X$ 中的每一个点必定属于某个 $X_n$，即：

    \[
    X = \bigcup_{n=1}^\infty X_n
    \]

    因为 $X$ 是 Banach 空间，它是一个完备的度量空间。根据 **Baire 纲定理**，一个完备空间绝不可能表示为可数个无处稠密集（稀疏集）的并集。
    
    因此，在序列 $\{X_n\}_{n=1}^\infty$ 中，至少存在一个闭集 $X_{n_0}$，它不是稀疏集。换句话说，$X_{n_0}$ 必须包含一个非空的内部。

    既然 $X_{n_0}$ 有非空内部，那么必定存在某一点 $x_0 \in X_{n_0}$ 以及一个半径 $r > 0$，使得以 $x_0$ 为中心、$r$ 为半径的闭球完全包含在 $X_{n_0}$ 中：

    \[
    \overline{B}(x_0, r) = \{ x \in X \mid \|x - x_0\| \le r \} \subseteq X_{n_0}
    \]

    对于闭球内的任意一点 $z \in \overline{B}(x_0, r)$，根据 $X_{n_0}$ 的定义，对所有的 $\alpha \in I$ 都有：

    \[
    \|T_\alpha z\| \le n_0
    \]

    现在，我们任取空间 $X$ 中范数满足 $\|x\| \le 1$ 的任意元素 $x$。
    
    我们构造元素 $z = x_0 + rx$。显然有 $\|z - x_0\| = \|rx\| = r\|x\| \le r$，因此 $z \in \overline{B}(x_0, r) \subseteq X_{n_0}$。

    由于 $x_0 \in X_{n_0}$ 且 $z \in X_{n_0}$，对于任意的 $\alpha \in I$，我们有 $\|T_\alpha x_0\| \le n_0$ 且 $\|T_\alpha z\| \le n_0$。

    利用算子 $T_\alpha$ 的线性和范数的三角不等式，我们可以对 $T_\alpha x$ 进行放缩：

    \[
    \|T_\alpha(rx)\| = \|T_\alpha(z - x_0)\| = \|T_\alpha z - T_\alpha x_0\| \le \|T_\alpha z\| + \|T_\alpha x_0\| \le n_0 + n_0 = 2n_0
    \]

    因为 $\|T_\alpha(rx)\| = r\|T_\alpha x\|$，所以我们得到：

    \[
    r\|T_\alpha x\| \le 2n_0
    \]

    进而导出：

    \[
    \|T_\alpha x\| \le \frac{2n_0}{r}
    \]

    这个不等式对所有 $\|x\| \le 1$ 的 $x$ 以及所有的 $\alpha \in I$ 都成立。根据算子范数的定义：

    \[
    \|T_\alpha\| = \sup_{\|x\| \le 1} \|T_\alpha x\| \le \frac{2n_0}{r}
    \]

    我们只需取 $M = \frac{2n_0}{r}$，即可得出 $\sup_{\alpha \in I} \|T_\alpha\| \le M < \infty$。至此，共鸣定理证明完毕。 $\square$

### 6.2 共鸣定理的重要应用

共鸣定理揭示了“局部（点态）性质”与“全局（一致）性质”之间的桥梁，在泛函分析中有着极为广泛的应用。

#### 6.2.1 算子列的强收敛性 (Banach-Steinhaus 定理)

!!! info "定理 12.4 (Banach-Steinhaus 定理)"

    设 $X$ 是 Banach 空间，$Y$ 是赋范线性空间。
    
    设 $\{T_n\}_{n=1}^\infty$ 是一列从 $X$ 到 $Y$ 的有界线性算子。如果对于空间 $X$ 中的任意一点 $x$，序列 $\{T_n x\}$ 在 $Y$ 中收敛（即算子列强收敛），那么：
    
    (i) 存在一个统一的界 $M > 0$，使得 $\sup_{n} \|T_n\| \le M$。
    
    (ii) 我们定义极限算子 $T(x) = \lim_{n \to \infty} T_n x$，则 $T$ 必定也是一个**有界线性算子**，即 $T \in \mathcal{B}(X, Y)$。

??? proof "证明（点击展开）"

    * 因为对于每一个 $x \in X$，序列 $\{T_n x\}$ 都是收敛的，而收敛序列必定是有界的。因此存在常数 $C_x$ 使得 $\sup_n \|T_n x\| \le C_x$。
    
    * $X$ 是 Banach 空间，这恰好满足共鸣定理的条件。直接应用共鸣定理，立即得到 $\sup_n \|T_n\| \le M < \infty$，此即结论 (i)。

    * 对于结论 (ii)，首先根据极限的线性运算法则，极限算子 $T$ 显然满足可加性和齐次性，因此 $T$ 是一个线性算子。

    * 接下来证明 $T$ 的有界性。对于任意的 $x \in X$，根据范数的连续性，有：

    \[
    \|Tx\| = \left\| \lim_{n \to \infty} T_n x \right\| = \lim_{n \to \infty} \|T_n x\|
    \]

    * 由于对所有的 $n$ 都有 $\|T_n x\| \le \|T_n\| \|x\| \le M \|x\|$，对其取极限自然得到：

    \[
    \|Tx\| \le M \|x\|
    \]

    * 这完美地证明了算子 $T$ 也是有界的，并且其范数满足 $\|T\| \le M$。 $\square$

#### 6.2.2 弱有界集与强有界集的等价性

在赋范线性空间中，子集的有界性可以从拓扑的两种不同视角来看。

!!! info "定理 12.5"

    设 $E$ 是一个赋范线性空间，$A$ 是 $E$ 中的一个子集。
    
    如果 $A$ 是**弱有界的**（即对于对偶空间 $E^*$ 中的任意一个有界线性泛函 $f$，集合 $\{f(x) \mid x \in A\}$ 都是有界的），那么 $A$ 必定是**强有界的**（即存在常数 $M$，使得对所有 $x \in A$ 都有 $\|x\| \le M$）。

??? proof "证明（点击展开）"

    * 为了应用共鸣定理，我们将空间中的元素反转视为泛函。借助于典范映射，对于每一个 $x \in A$，我们定义二次对偶空间 $E^{**}$ 中的泛函 $x^{**}$：

    \[
    x^{**}(f) = f(x), \quad \forall f \in E^*
    \]

    * 根据定理的假设，对于任何固定的 $f \in E^*$，数值集合 $\{ f(x) \mid x \in A \}$ 是有界的。这等价于说：对于任意的 $f \in E^*$，存在常数 $C_f$ 使得：

    \[
    \sup_{x \in A} |x^{**}(f)| \le C_f < \infty
    \]

    * 我们注意到，对偶空间 $E^*$ 始终是一个完备的 **Banach 空间**，而 $\{x^{**}\}_{x \in A}$ 是定义在 $E^*$ 上的一族有界线性算子。

    * 这完全满足共鸣定理的条件。应用共鸣定理，这族泛函在算子范数意义下必定是一致有界的，即存在常数 $M$，使得：

    \[
    \sup_{x \in A} \|x^{**}\| \le M
    \]

    * 回顾典范映射的性质，我们已经证明过 $\|x^{**}\| = \|x\|$。因此：

    \[
    \sup_{x \in A} \|x\| \le M
    \]

    * 这说明子集 $A$ 在原空间的范数下是有界的，即 $A$ 是强有界集。 $\square$

#### 6.2.3 连续函数傅里叶级数的发散性

这是共鸣定理在经典分析中最著名、最震撼的应用之一：它能够非构造性地证明，存在连续函数，其傅里叶级数在某一点上是发散的。

!!! info "定理 12.6"

    在周期为 $2\pi$ 的连续函数空间 $C_{2\pi}$ 中，必定存在一个连续函数 $f$，使得它的傅里叶级数在点 $t=0$ 处不收敛（发散）。

??? proof "证明概览（点击展开）"

    * 设 $X = C_{2\pi}$ 是所有以 $2\pi$ 为周期的连续函数构成的 Banach 空间，赋予最大值范数 $\|f\|_\infty = \max_{t} |f(t)|$。
    
    * 设 $Y = \mathbb{R}$。对于任何 $f \in C_{2\pi}$，其傅里叶级数的前 $n$ 项部分和在 $t=0$ 处的值可以通过 Dirichlet 积分表示：

    \[
    S_n(f, 0) = \frac{1}{2\pi} \int_{-\pi}^{\pi} f(t) D_n(t) dt
    \]

    * 其中 $D_n(t) = \frac{\sin((n+1/2)t)}{\sin(t/2)}$ 是 Dirichlet 核。
    
    * 我们定义一列有界线性泛函 $T_n : C_{2\pi} \to \mathbb{R}$ 为：

    \[
    T_n(f) = S_n(f, 0)
    \]

    * 通过计算可以严格证明，泛函 $T_n$ 的算子范数正好等于 Dirichlet 核的 $L^1$ 范数：

    \[
    \|T_n\| = \frac{1}{2\pi} \int_{-\pi}^{\pi} |D_n(t)| dt
    \]

    * 数学分析中的经典结论表明，Dirichlet 核的积分是无界的（其增长阶对数级），即当 $n \to \infty$ 时：

    \[
    \|T_n\| \to \infty
    \]

    * 我们采用反证法。如果每一个连续函数 $f \in C_{2\pi}$ 的傅里叶级数在 $t=0$ 处都收敛，那么对于每一个给定的 $f$，序列 $\{T_n(f)\}$ 必定是收敛的，因而必然是有界的：

    \[
    \sup_n |T_n(f)| < \infty \quad (\forall f \in C_{2\pi})
    \]

    * 既然 $X$ 是 Banach 空间，并且满足点态有界条件。根据共鸣定理，必定存在一个统一的常数 $M$ 使得：

    \[
    \sup_n \|T_n\| \le M < \infty
    \]

    * 这与我们之前计算得出的 $\|T_n\| \to \infty$ 产生了不可调和的彻底矛盾！
    
    * 矛盾表明，原假设必定是错误的。因此，必定至少存在一个连续函数 $f \in C_{2\pi}$，使得它的傅里叶级数序列 $\{S_n(f, 0)\}$ 是无界的，从而在 $t=0$ 处发散。 $\square$
