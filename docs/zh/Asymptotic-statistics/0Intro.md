# 📊 渐近统计 (Asymptotic Statistics)

!!! abstract "📈 课程基本信息(Course Metadata)"

    * **开课单位**：数学科学学院 & 数据科学中心（CDS）
    
    * **先修要求**：数学分析、高等代数、概率论、数理统计、实变函数
    
    * **课程性质**：32学时 博士生课程
