    4.1 符号测度与 Hahn-Jordan 分解

    在前面的章节中，测度总是被定义为非负的集函数（代表长度、面积、体积或概率）。然而，在很多物理和数学场景中（如电荷分布可以有正负，或者两个积分之间的差值），我们需要允许“测度”取负值。这就引出了符号测度 (Signed Measure)，也称为变号测度的概念。

    1. 符号测度的基本概念

    定义 4.1.1 (符号测度 Signed Measure)

    设 \((X, \mathcal{M})\) 为一个可测空间。集函数 \(\nu: \mathcal{M} \to [-\infty, +\infty]\) 被称为一个符号测度，如果它满足以下三个条件：

    • 空集为零：
    \[ \nu(\emptyset) = 0 \]

    • 至多取一个无穷：\(\nu\) 最多只能取 \(+\infty\) 或 \(-\infty\) 中的一个值（以避免出现 \(\infty - \infty\) 这种无意义的运算）。

    • 可数可加性：对于 \(\mathcal{M}\) 中任意互不相交的集合列 \(\{E_j\}_{j=1}^\infty\)，都有：

    \[ \nu\left(\bigcup_{j=1}^\infty E_j\right) = \sum_{j=1}^\infty \nu(E_j) \]

    并且，如果并集的测度 \(\nu(\bigcup_{j=1}^\infty E_j)\) 是有限的，那么上述级数必定是绝对收敛的。

    • 注 1：普通测度（非负测度）自然是符号测度的一种特例。
    • 注 2：符号测度最典型的例子是由积分诱导的测度。设 \(\mu\) 是一般测度，\(f\) 是一个变号的 \(\mu\)-可积函数（或者至少其正部或负部之一的积分为有限值），定义：
    \[ \nu(E) = \int_E f \, d\mu \]

    那么 \(\nu\) 就是一个符号测度。

    2. 正集、负集与零集

    对于符号测度，由于集合的测度可以被正负抵消，仅知道 \(\nu(E) > 0\) 并不能说明 \(E\) 内部全是“正”的（可能只是正的部分比负的部分多）。因此，我们需要严格定义什么是“纯粹”的正集。

    定义 4.1.2 (正集、负集与零集)

    设 \(\nu\) 为 \((X, \mathcal{M})\) 上的符号测度，\(E \in \mathcal{M}\)。

    • 正集 (Positive Set)：如果对于 \(E\) 的任意可测子集 \(F \subset E\)（\(F \in \mathcal{M}\)），都有 \(\nu(F) \ge 0\)，则称 \(E\) 为 \(\nu\) 的一个正集。

    • 负集 (Negative Set)：如果对于 \(E\) 的任意可测子集 \(F \subset E\)，都有 \(\nu(F) \le 0\)，则称 \(E\) 为 \(\nu\) 的一个负集。

    • 零集 (Null Set)：如果对于 \(E\) 的任意可测子集 \(F \subset E\)，都有 \(\nu(F) = 0\)，则称 \(E\) 为 \(\nu\) 的一个零集。

    显然，零集既是正集又是负集。同时要注意区分“零集”和“测度为零的集合”：测度为零的集合可能包含测度为一正一负且相互抵消的子集，但零集的所有子集测度必须严格为 0。

    引理 4.1.1

    任意可数个正集的并集仍然是正集。

    引理 4.1.1 的证明

    设 \(\{P_j\}_{j=1}^\infty\) 是一列正集。我们希望证明 \(P = \bigcup_{j=1}^\infty P_j\) 也是正集。

    首先，我们将这列集合正交化（互不相交化）。定义：

    \[ E_n = P_n \setminus \bigcup_{j=1}^{n-1} P_j \]

    显然 \(E_n \subset P_n\)，因为正集的任意可测子集仍是正集，所以 \(E_n\) 全是正集，且它们互不相交，且 \(\bigcup_{n=1}^\infty E_n = P\)。

    现在任取 \(F \subset P\) 且 \(F \in \mathcal{M}\)。我们可以将 \(F\) 拆分为 \(F = \bigcup_{n=1}^\infty (F \cap E_n)\)。 由于 \(F \cap E_n \subset E_n\)，且 \(E_n\) 是正集，故 \(\nu(F \cap E_n) \ge 0\)。

    利用符号测度的可数可加性：

    \[ \nu(F) = \sum_{n=1}^\infty \nu(F \cap E_n) \ge 0 \]

    这证明了 \(P\) 是一个正集。

    3. Hahn 分解定理 (Hahn Decomposition)

    Hahn 分解定理指出了一个极其优美的几何图景：对于任何符号测度，我们总是可以把全空间像切西瓜一样，“干净利落”地切成完全正的一半和完全负的一半，没有任何模糊地带。

    定理 4.1.1 (Hahn 分解定理)

    设 \(\nu\) 为可测空间 \((X, \mathcal{M})\) 上的一个符号测度。

    则必定存在一个正集 \(P\) 和一个负集 \(N\)，满足：

    • \(P \cup N = X\)

    • \(P \cap N = \emptyset\)

    这对分解 \((P, N)\) 称为空间 \(X\) 关于 \(\nu\) 的 Hahn 分解。并且该分解在相差一个 \(\nu\)-零集的意义下是唯一的。

    Hahn 分解定理的证明（核心思路展开）

    不失一般性，我们假设符号测度 \(\nu\) 不取 \(+\infty\)（若不取 \(-\infty\) 则对 \(-\nu\) 证明即可）。这意味着 \(\nu\) 在所有可测集上有上界。

    第一步：榨取最大的正集

    定义 \(m = \sup\{\nu(A) \mid A \text{ 是正集}\}\)。因为空集是正集且 \(\nu(\emptyset) = 0\)，所以 \(m \ge 0\)。 由上确界的定义，存在一列正集 \(\{P_j\}\)，使得 \(\lim_{j \to \infty} \nu(P_j) = m\)。 令 \(P = \bigcup_{j=1}^\infty P_j\)。由引理 4.1.1，\(P\) 也是一个正集。因此 \(\nu(P) \le m\)。 由于 \(P_j \subset P\)，且 \(P\) 是正集，所以 \(\nu(P) = \nu(P_j) + \nu(P \setminus P_j) \ge \nu(P_j)\)。令 \(j \to \infty\)，得到 \(\nu(P) \ge m\)。 综上可知 \(\nu(P) = m\)。因为 \(\nu\) 不取 \(+\infty\)，所以 \(m < \infty\)。

    第二步：证明剩余部分是负集

    令 \(N = X \setminus P\)。我们断言 \(N\) 是一个负集。 采用反证法：假设 \(N\) 不是负集，那么 \(N\) 中必定包含一个测度严格大于 0 的子集 \(E\)。然而，\(E\) 未必是正集（它里面可能还夹杂着负的成分）。 我们可以通过一个不断剔除负子集的过程（穷竭法），在 \(E\) 中提炼出一个真正的正集 \(A \subset E\)，且 \(\nu(A) > 0\)。

    此时，考察集合 \(P \cup A\)。由于 \(P\) 是正集，\(A\) 也是正集，且它们互不相交，所以 \(P \cup A\) 是一个全新的正集。 计算其测度：

    \[ \nu(P \cup A) = \nu(P) + \nu(A) = m + \nu(A) > m \]

    这与 \(m\) 是所有正集测度的上确界相矛盾！ 因此，\(N\) 绝不能包含任何具有正测度的子集，\(N\) 必定是一个负集。

    第三步：唯一性

    假设存在另一组 Hahn 分解 \((P', N')\)。考察 \(P \setminus P'\)。 因为 \(P \setminus P' \subset P\)，所以它是一个正集，其测度 \(\ge 0\)。 同时 \(P \setminus P' \subset N'\)（因为全空间被互补分割），所以它也是一个负集，其测度 \(\le 0\)。 这说明 \(P \setminus P'\) 只能是一个零集。同理可证它们差异的各个部分均为零集。

    4. Jordan 分解定理与全变差

    利用 Hahn 分解，我们可以将一个符号测度自然地拆分为两个互相独立的、非负的常规测度之差。

    首先，我们需要定义测度之间的“互相独立性”，即相互奇异 (Mutually Singular)。

    定义 4.1.3 (相互奇异测度)

    设 \(\mu_1, \mu_2\) 为同一可测空间上的两个非负测度。如果存在互不相交的集合 \(E, F \in \mathcal{M}\)，满足：

    • \(E \cup F = X\)

    • \(\mu_1(F) = 0\) 且 \(\mu_2(E) = 0\)

    则称测度 \(\mu_1\) 和 \(\mu_2\) 是相互奇异的，记为 \(\mu_1 \perp \mu_2\)。这在直观上意味着这两个测度各自“存活”在不相交的地盘上。

    基于相互奇异的概念，我们引出 Jordan 分解：

    定理 4.1.2 (Jordan 分解定理)

    任何一个符号测度 \(\nu\) 都可以被唯一地分解为两个相互奇异的非负测度之差，即：

    \[ \nu = \nu^+ - \nu^- \]

    且 \(\nu^+ \perp \nu^-\)。这被称为 \(\nu\) 的 Jordan 分解。\(\nu^+\) 称为正变差，\(\nu^-\) 称为负变差。

    Jordan 分解定理的构造与证明

    设 \((P, N)\) 为 \(X\) 关于 \(\nu\) 的 Hahn 分解。 对于任意可测集 \(E \in \mathcal{M}\)，我们定义：

    \[ \nu^+(E) = \nu(E \cap P) \]
    \[ \nu^-(E) = -\nu(E \cap N) \]

    显然： 1. 由于 \(P\) 是正集，\(N\) 是负集，\(\nu^+\) 和 \(\nu^-\) 都是非负的测度。 2. 对于任意 \(E \in \mathcal{M}\)，有 \(\nu(E) = \nu(E \cap P) + \nu(E \cap N) = \nu^+(E) - \nu^-(E)\)。 3. 取 \(E=P, F=N\)，显然 \(P \cup N = X\)。由于 \(\nu^-(P) = -\nu(P \cap N) = \nu(\emptyset) = 0\)，同理 \(\nu^+(N) = 0\)，这就证明了 \(\nu^+ \perp \nu^-\)。

    关于唯一性，任何满足 \(\nu = \lambda^+ - \lambda^-\) 且 \(\lambda^+ \perp \lambda^-\) 的分解，其支撑集必然能构成原符号测度的 Hahn 分解，由 Hahn 分解的唯一性（差一个零集）可反推 Jordan 分解测度的唯一性。

    定义 4.1.4 (全变差 Total Variation)

    对于符号测度 \(\nu = \nu^+ - \nu^-\)，我们定义其全变差 (Total Variation) 为：

    \[ |\nu| = \nu^+ + \nu^- \]

    \(|\nu|\) 是一个标准的非负测度。如果 \(|\nu|(X) < \infty\)，则称 \(\nu\) 是一个有限符号测度。 对于任意集合 \(E\)，全变差测度满足 \(|\nu(E)| \le |\nu|(E)\)。

    符号测度的积分

    对于一个符号测度 \(\nu = \nu^+ - \nu^-\)，由于 \(\nu^+\) 和 \(\nu^-\) 都是普通的非负测度，我们可以自然地定义关于符号测度的积分。

    设 \(f\) 为可测函数，如果 \(\int |f| d|\nu| < \infty\)（即 \(f \in L^1(|\nu|)\)），则定义 \(f\) 关于 \(\nu\) 的积分为：

    \[ \int_X f \, d\nu = \int_X f \, d\nu^+ - \int_X f \, d\nu^- \]

    由此可见，可积函数空间完全由全变差测度决定，即 \(L^1(\nu) = L^1(|\nu|)\)。
